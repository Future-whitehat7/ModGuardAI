## 🎨 Color Scheme

- Primary: Indigo (#6366F1)
- Secondary: Purple (#8B5CF6)
- Accent: Pink (#EC4899)
- Background: Dark Blue (#0F172A)
- Surface: Lighter Dark (#1E293B)
- Text: White (#F8FAFC)
- Success (Real): Green (#10B981)
- Error (Fake): Red (#EF4444)
- Warning (Inconclusive): Orange (#F59E0B)

## 🔄 Navigation Flow

```
Welcome → Onboarding → Signup → Main App
                    ↓
                  Login → Main App

Main App (Bottom Tabs):
├── Home (Dashboard)
├── Challenges (Daily challenges)
├── Scan (Media verification)
├── Labs (Earnings/Labeling)
└── Profile (User stats/settings)
```

## 🎯 Key Interactions

1. **Swipe gestures** on challenge cards (left = fake, right = real)
2. **Pull to refresh** on list screens
3. **Tap cards** for details
4. **Long press** for options menu
5. **Haptic feedback** on button taps
6. **Smooth animations** between screens (200-300ms)
7. **Loading states** with spinners
8. **Error states** with retry buttons

## 📱 Responsive Design

- Adapts to different screen sizes (iPhone SE to iPad)
- Safe area insets for notched devices
- Landscape support for media playback
- Dynamic font sizing for accessibility
